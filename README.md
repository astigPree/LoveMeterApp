# ❤️ Kivy Love Calculator App

This repository contains a simple mobile application built with **Kivy**, a Python framework for developing cross-platform apps.  
The app playfully checks **"how much love you have for a person’s name"**, making it a fun beginner project to explore Kivy’s UI and logic capabilities.

## 📱 Features
- Built with **Kivy** for cross-platform compatibility (Android, iOS, Windows, Linux, macOS).
- User enters a **name** to calculate a playful "love percentage."
- Simple and intuitive interface for beginners.
- Great starting point for learning Kivy app development.

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Kivy framework installed
